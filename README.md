# Barbut Game (Craps)

## English
A classic Barbut (Craps) dice game implemented in Java. The program simulates rolling dice and implements the standard rules of the Barbut game.

### Features
- Random dice roll simulation.
- Java console-based application.

---

## Türkçe
Java diliyle geliştirilmiş klasik Barbut (Zar) oyunu. Program, zar atma simülasyonu yapar ve standart Barbut oyunu kurallarını uygular.

### Özellikler
- Rastgele zar atma simülasyonu.
- Konsol tabanlı Java uygulaması.
