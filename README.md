## 🇬🇧 English
A robust and classic implementation of the popular dice game **Barbut (Craps)**, written entirely in Java. This project demonstrates core Object-Oriented Programming (OOP) concepts, random number generation, and console-based logic flows.

### ✨ Features
- 🎰 **Random Dice Rolls**: Utilizes Java's random class to simulate realistic dice rolls.
- 📜 **Standard Rules**: Implements the authentic rules of the Barbut game.
- 💻 **Terminal Interface**: Easy-to-play text-based interface.

### 🚀 How to Run
```bash
javac zar.java
java zar
```
